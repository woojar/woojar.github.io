# Changelog

All notable changes to this project will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-05-19

### Added
- Initial public release of the `Signal` theme
- Dark mode with system-preference detection and manual toggle
- Inline client-side search with keyboard shortcut (`/`)
- Reading progress bar
- Back-to-top button
- Giscus comments integration
- Social sharing (Twitter, LinkedIn, Facebook, copy-link)
- Author bio block
- Newsletter signup block
- Related posts (tag-based)
- Post prev/next navigation
- Word count & reading time
- Breadcrumbs
- Schema.org JSON-LD (BlogPosting / WebSite)
- Open Graph & Twitter Cards
- `index.json` for search indexing
- Print styles
- Reduced-motion support
- Skip-link for accessibility
- Fully responsive (mobile-first, 3 breakpoints)
